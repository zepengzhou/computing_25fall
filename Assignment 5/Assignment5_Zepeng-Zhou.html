5-1. SVM Model¶

  • The training set was first used to train a Support Vector Machine (SVM) classifier,
    and its performance was evaluated on the test set.
  • Then, I chose to tune the SVM model using GridSearchCV,
    performing a grid search over the penalty parameter C and kernel parameter \gamma.
  • The macro-averaged F1 score (macro-F1) was used as the optimization criterion,
    and the model was re-evaluated after finding the optimal parameter combination.

def build_model(input_dim, hidden_units=16, lr=1e-3):
    model = keras.Sequential([
        layers.Input(shape=(input_dim,)),
        layers.Dense(hidden_units, activation="relu"),
        layers.Dense(3, activation="softmax")   # Iris 三分类
    ])
    model.compile(
        optimizer=keras.optimizers.Adam(learning_rate=lr),
        loss="sparse_categorical_crossentropy",
        metrics=["accuracy"]
    )
    return model

  • For the fourth method, I chose Ridge Logistic Regression.
  • Ridge Logistic Regression is a variant of logistic regression
    that introduces an L2 regularization term to prevent overfitting and enhance model stability.
  • I first standardized the Iris dataset and trained a multinomial logistic regression model
    with an L2 penalty (penalty='l2'), generating a classification report and confusion matrix to evaluate its performance.
  • Then, I applied 5-fold cross-validation to compute the mean Accuracy and Macro-F1 scores,
    assessing the model’s overall generalization performance across different data splits.

Conclusion¶

Based on the 5-fold cross-validation results, all four models performed very similarly on the Iris dataset,
with both accuracy and macro-F1 scores around 0.95.

This suggests that the dataset has well-separated features and low noise, allowing different algorithms to learn the class boundaries effectively.
If one model must be recommended, SVM (Support Vector Machine) would be the preferred choice.
It achieved slightly higher mean accuracy and macro-F1 in this experiment, while maintaining a simple structure, fast training speed, and stable performance on small datasets.

However, if model interpretability or scalability to larger datasets is a priority,
Ridge Logistic Regression is also an excellent alternative, offering interpretability and low computational cost.


Overall, the four models achieved nearly identical predictive performance,
but SVM performed slightly better and most consistently, making it the recommended model.
