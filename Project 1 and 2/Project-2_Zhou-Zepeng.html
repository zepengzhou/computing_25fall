Introduction ¶

This project analyzed 186 short dramas from the Best Short Drama list on IMDb,
examining their basic information to reveal audience rating trends and engagement patterns.
It highlights the rapid surge of short dramas in recent years
and uncovers the structural characteristics behind this phenomenon
— including the dominance of certain platforms, the concentration of production companies,
and the uneven distribution of content types.

Key Findings

  • The overall ratings of short dramas on IMDb are relatively high, with an average of 7.48 and most clustered between 7 and 8, indicating that short dramas are generally well received by audiences.
  • The distribution of review counts is highly right-skewed—most short dramas have few reviews, while a small number of popular titles attract many, showing a clear “long-tail” effect.
  • The number of short dramas increased significantly starting in 2023 and exploded in 2024, reflecting the global rise of this content format.
  • Platform distribution is highly uneven, with ReelShort, GoodShort, and DramaBox dominating, especially ReelShort, which holds a clear leading position in the industry.
  • Although there are many production companies, production is concentrated among a few—New Leaf Publishing and ReelShort are the main producers, reflecting an “oligopolistic” structure.
  • In terms of genre, romance dominate, showing that short drama creation centers on emotional storytelling, while other genres such as comedy, fantasy, and action serve as supplements.

Variable: Review count

  • For the variable “number of reviews,” it is currently coded as follows:
    (1) If the number is below 1,000, it appears with a “–” sign in front;
    (2) If it exceeds 1,000, it is displayed as “(number + k).” For example, “(2.6k)” means over 2,600 reviews.
    I believe these extra symbols were introduced by the crawler’s parsing process rather than by the original webpage.
    After comparing the scraped data with the source webpage, I confirmed that the numerical values are accurate.
    The original webpage indeed only shows values over 1,000 in the “k” format instead of providing exact counts.
    I recoded this variable using regular expressions to extract only the numeric component,
    and for values above 1,000, I converted them by multiplying the extracted number by 1,000.

import re # Import the regular expression library

# Define a function to clean and standardize review count values
def clean_review_count(value):
    # If the value is missing (NaN), return NaN
    if pd.isna(value):
        return np.nan
    
    # Convert the value to a lowercase string and remove extra spaces
    value = str(value).lower().strip()

    # Remove any symbols except digits, dots, and 'k' (e.g., remove brackets, dashes, spaces)
    value = re.sub(r'[^0-9.k]', '', value)

    # If the value contains 'k', it means the number is in thousands (e.g., '2.6k' → 2600)
    if 'k' in value:
        try:
            return int(float(value.replace('k', '')) * 1000)
        except:
            return np.nan

    # Otherwise, extract the digits directly (e.g., '345' → 345)
    digits = re.findall(r'\d+', value)
    return int(digits[0]) if digits else np.nan

import re  

# Define a function to clean and standardize the 'year' variable
def clean_year(value):
    # If the value is missing (NaN), return NaN
    if pd.isna(value):
        return np.nan
    
    # Convert the value to a string and remove leading/trailing spaces
    value = str(value).strip()
    
    # Extract all four-digit numbers (e.g., 2024, 2025) using a regular expression
    years = re.findall(r'\d{4}', value)
    
    # If multiple years are found (e.g., "2024–2025"), keep only the first one
    if len(years) > 0:
        return int(years[0])
    else:
        return np.nan


# Apply the cleaning function to the 'year' column and store the results in a new column

Variable: Platforms

I found that in the variables platform1 and platform2, aside from the missing values,
there are some entries that are clearly not platform names
(for example, “link to the official site” or “Website”).

After checking the original webpages,
I realized that the “platform” section often contains hyperlinks
rather than directly displaying the platform names.
However, during the scraping process, I captured the text content of that section instead of the actual link targets.

Since the sample size is relatively small,
I manually corrected these cases:

  • I visited the webpages of the misclassified short dramas,
  • clicked on their platform links to identify the actual platforms, and updated them manually.

If I encounter similar situations in the future,
I will adjust my scraping algorithm to automatically click into those links
and extract the platform names directly from the URL.

In addition, there are some duplicate cases in the variables platform1 and platform2,
where both columns indicate the same platform.
In such cases, I kept the value in platform1
and replaced the corresponding entry in platform2 with a missing value.

# Select all columns that start with 'genre' and end with a digit (e.g., genre1, genre2, genre3)
# This excludes any other unrelated columns that might contain the word 'genre'
genre_cols = [c for c in drama_data.columns if c.startswith('genre') and c[-1].isdigit()]

# Convert each genre column to string and remove leading/trailing spaces
for c in genre_cols:
    drama_data[c] = drama_data[c].astype('string').str.strip()

# Define a function to remove duplicate genres within the same row
def dedupe_genres(row):
    seen = set() # Keep track of genres already encountered in the current row
    for c in genre_cols:
        val = row[c] # Current genre value
        key = val.lower().strip() if pd.notna(val) else val # Normalize text for comparison (ignore case and spaces)
        # If the genre is not missing:
        if pd.notna(val):
            # If it's already in the set (duplicate), replace it with NaN
            if key in seen:
                row[c] = np.nan
            # Otherwise, add it to the 'seen' set
            else:
                seen.add(key)
    return row # Return the cleaned row

# Apply the deduplication function to every row in the DataFrame
# This ensures that genre1, genre2, and genre3 in each row are unique
drama_data[genre_cols] = drama_data[genre_cols].apply(dedupe_genres, axis=1)

Rating and Review Count

First, I examined the distribution of two key numerical variables in the dataset:
Rating and Review Count.

  • Rating
    From the overview results above, we can see that the average rating is 7.48.
    Based on the distribution below, the ratings show a slightly right-skewed pattern,
    with most short dramas receiving relatively high scores between 7 and 8.
    This indicates that short dramas on IMDb generally have higher ratings,
    with mainstream works widely appreciated by audiences.
    The concentration of ratings within the 7–8 range suggests that
    the overall quality of short dramas on the platform is relatively high,
    while it may also reflect a selection bias in user rating behavior.

  • Review Count
    From the overview results above, we can see that the average review count is 195.
    From the figure below, the distribution of Review Count shows a highly right-skewed pattern.
    The vast majority of short dramas have between 0 and 500 reviews,
    while only a very small number exceed 1,000, with some reaching 6,000.
    This long-tail distribution indicates a highly uneven pattern of audience engagement.
    This suggests that most short dramas receive relatively few audience reviews,
    while only a handful of popular titles attract exceptionally high levels of attention.
    A small number of top-performing dramas capture the majority of traffic and reviews,
    whereas medium- and small-scale productions generally experience limited audience participation.
